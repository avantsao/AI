## Documentation

This repository currently contains no source modules to document. This documentation scaffolding provides a clear structure to add API, component, and guide content as code is introduced.

### Navigation
- **API Reference**: See `docs/api/README.md`
- **Components**: See `docs/components/README.md`
- **Guides**: See `docs/guides/writing-docs.md`
- **Examples**: See `docs/examples/README.md`

### How to use this docs structure
- **Add a new module**: Create a page under `docs/api/` following the `_TEMPLATE.md`.
- **Add a new component**: Document it in `docs/components/` with props and examples.
- **Add examples**: Put runnable snippets in `docs/examples/`.

### Style and standards
- Prefer clear function/component names; document parameters, return values, and edge cases.
- Provide at least one realistic example per public API and component.
- When applicable, include error cases and performance notes.
